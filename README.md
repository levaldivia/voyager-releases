# Voyager

Download the [Stable installer](https://github.com/levaldivia/voyager-releases/releases/latest). Requires Apple Silicon and macOS 15 or newer.

Open the DMG, drag Voyager to Applications, then launch it. There is one installer; it defaults to Stable.

In **Voyager → Update Settings…**, choose **Stable** or **Nightly**. Nightly updates arrive after successful merges into main. Switching channels preserves your workspace and conversations. Switching back to Stable waits for a newer Stable version rather than downgrading.

ZIP assets are signed automatic-update payloads used by Voyager. Nightly has no separate installer or GitHub release entry.
